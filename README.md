# Anshul Palarpwar — Portfolio

Personal site for [Anshul Palarpwar](https://github.com/Anshul3977): a dark editorial portfolio of selected full-stack and AI work.

## Stack

Next.js (App Router), TypeScript, Tailwind CSS, Motion.

## Local development

```bash
npm install
npm run dev
```

## Content

Project copy lives in `content/projects.ts` and is taken from public GitHub READMEs. There is no resume link because no resume file was found in the public repositories.
